# 🎉 Happy 25th Birthday Alan!

An interactive 3D flip birthday card built with React, Vite, and Tailwind CSS.

## Features

- 🎴 3D flip animation - click to open the card
- 🎂 Sports-themed birthday cake
- 📸 Photo gallery with 6 memories
- 🎵 Spotify player with "Mistletoe" by Justin Bieber
- 📱 Fully responsive design

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## Building for Production

```bash
npm run build
```

## Technologies

- React 18
- Vite 5
- Tailwind CSS 3
- JavaScript/JSX
